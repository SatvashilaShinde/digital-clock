⏰ Digital Clock

A simple and responsive Digital Clock built using HTML, CSS, and JavaScript.
It displays the current time in real-time and updates every second.

🚀 Features
Displays current system time
Updates every second automatically
Clean and simple UI
Built with pure JavaScript (no libraries)

🛠️ Technologies Used
HTML
CSS
JavaScript

📂 Project Structure
Digital-Clock/
│── index.html

💡 How It Works
Uses JavaScript setInterval() function to update time every second
Fetches current time using Date() object
Displays time using toLocaleTimeString()
